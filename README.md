# African Footprint Technologies

Official website codebase for African Footprint Technologies (AFT).

## Brand

**Clouding a Brighter Africa**  
Same Continent. Greater Possibilities.

AFT is positioned as a cloud-first technology consulting and solutions partner helping organisations build, secure and scale their technology footprint across Africa.

## Stack

- Next.js
- React
- TypeScript
- Responsive CSS

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Current status

Initial responsive homepage is implemented. Contact details and corporate registration details remain placeholders until confirmed. The brand mark is currently a CSS-rendered approximation of the approved Option 1 fingerprint/cloud concept; a final vector logo should replace it once the logo artwork is finalised.
